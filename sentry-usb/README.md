# Sentry-USB 導入ガイド

Tesla のセントリーモード用スマート USB ドライブ「Sentry-USB」を導入するための、日本国内ユーザー向けのクイックガイドです。詳細なドキュメントは [external/README.md](external/README.md) および [external/wiki](external/wiki/Home.md)（日本語訳済み）を参照してください。

## 1. 必要なハードウェア（機材）

Sentry-USB を動かすために、以下の機材を揃える必要があります。

- **Raspberry Pi 本体**:
    - **推奨**: **Raspberry Pi 4B または 5** (処理が速く、最も安定しています)
    - **廉価版**: **Raspberry Pi Zero 2 W** (小型で車内でも場所を取りませんが、処理は少し重めです)
- **microSD カード / SSD**:
    - **SD カードのみの場合**: **128GB 以上を推奨**。書き換えに強い「高耐久（Endurance）」モデル（Samsung PRO Endurance 等）が必須です。
    - **SSD 併用の場合**: OS 起動用に 16GB 程度の microSD カードがあれば、あとは USB 外付け SSD をデータ保存用として使えます。容量・寿命・速度の面で SSD 併用が最も推奨されます。
- **USB ケーブル（データ転送対応）**:
    - **注意**: 充電専用ケーブルでは車両が認識しません。必ずデータ転送可能なものを選んでください。
    - Pi 4/5 なら「USB-A to USB-C」、Pi Zero 2 W なら「USB-A to Micro-USB」が必要です。

## 2. 設置場所と熱対策

テスラ車内、特に夏場は非常に高温になるため、適切な設置と対策が重要になります。

- **設置場所**:
    - **2021 年以降モデル**: グローブボックス内の USB ポートが、直射日光を避けられセキュリティ上も最適です。
    - **2020 年以前モデル**: センターコンソールの USB ポート。
- **熱対策**:
    - **ケース**: ヒートシンク付きの金属ケースや、小型ファン付きのケースの使用を強く推奨します。
    - **直射日光を避ける**: ケーブルを延長してコンソールボックス内に隠すなど、日光が直接当たらない工夫をしてください。

## 3. Sentry-USB の主な特徴

標準の USB メモリにはない、高度な機能が備わっています。

- **録画中の並行再生**: 車が録画を継続したまま、スマホ等のブラウザから過去の映像をすぐにチェックできます。
- **自動アーカイブ**: 自宅 Wi-Fi に繋がると、録画データを NAS やクラウドへ自動でバックアップします。
- **マルチカメラビューアー**: Tesla の全 6 カメラの映像を同期して同時再生できます。

## 4. ネットワーク通信の仕組み

Sentry-USB は、状況に合わせて 3 つの通信方法を自動で使い分けます。

- **自宅 Wi-Fi (クライアントモード)**: 
    - 録画データを NAS やクラウド（Google Drive 等）へ自動転送します。
- **外出先 Wi-Fi (アクセスポイントモード)**: 
    - Pi 自体が Wi-Fi 親機（SSID: `SentryUSB`）になり、車内からスマホで Web UI にアクセスできます。
- **Bluetooth LE (BLE)**: 
    - 初回の Wi-Fi 設定や、iOS アプリ「Sentry Connect」での簡易的なステータス確認に使用します。

## 5. セットアップの流れ

1. **OS イメージの作成**: PC で SD カードに専用イメージを書き込みます。
2. **車両に接続**: 車の指定ポートに接続します。
3. **Web UI で設定**:
    - スマホや PC から `http://sentryusb.local`（自宅 Wi-Fi）または `http://192.168.66.1`（直接接続）を開きます。
    - 「セットアップウィザード」に従って、Wi-Fi と保存先を設定します。
4. **自動セットアップ**: 適用すると Pi が数回再起動し（約 10〜20 分）、完了すると Tesla が USB ドライブとして認識します。

## 6. 安定動作と信頼性について

「録画が途切れる」リスクを最小限にするための注意点です。

- **高耐久メディアの徹底**: 録画が止まる最大の原因は、SD カードの書き込み速度不足や寿命です。
- **安定した電源**: Pi 4/5 を使う場合は、電力不足にならないよう質の良いケーブルを使用してください。
- **読み取り専用 OS**: システム自体を読み取り専用で動かすことで、突然の電源断（車両のシャットダウン）による OS 破損を防いでいます。

## 💡 推奨アプリ
iPhone をお使いの場合、App Store から **[Sentry Connect](https://apps.apple.com/app/sentry-connect/id6759679030)** をインストールすると、プッシュ通知やライブアクティビティでの進捗確認ができて便利です。
